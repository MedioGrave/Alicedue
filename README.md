# Pianta AliceDue

App per telefono per progettare l'arredamento della casa sulla pianta in scala reale (1:10, misure in cm).

- Pianta vettoriale fedele al progetto, con quote e nomi delle stanze attivabili
- Catalogo arredi con dimensioni modificabili e ricerca
- Misure tra due punti e superfici, con aggancio a muri e spigoli
- Distanze libere dai muri, guida di centratura, avviso sovrapposizioni
- Più ipotesi di arredo, esportazione immagine, esporta/importa dati

## Pubblicazione con GitHub Pages
1. Carica tutti i file di questa cartella nella radice del repository (anche `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, cartella `/ (root)` → Save.
3. Dopo un minuto l'app è su `https://<utente>.github.io/<repository>/`.

## Sul telefono
Apri il link in Safari → Condividi → **Aggiungi alla schermata Home**: si apre a tutto schermo come un'app.

Le ipotesi si salvano nel telefono (memoria del browser). Per spostarle da un dispositivo all'altro usa
**Ipotesi → Esporta dati** e poi **Importa** sull'altro dispositivo.
